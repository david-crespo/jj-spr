# Configuration

The recommended way to configure jj-spr is to run `jj spr init`, rather than setting config values manually. You can rerun `jj spr init` to update config at any time.

## Configuration Storage

**How it works:**
- `jj spr init` writes configuration to your repository's **Jujutsu config** with `jj config set --repo`. Current versions of jj keep that file outside the repository. `jj config path --repo` prints where it is.
- At runtime, jj-spr reads from **Jujutsu config** first, then falls back to **git config**, so settings in git config still work when jj config doesn't have them.

**Configuration priority (highest to lowest):**
1. Command-line flags (`--github-auth-token`, `--github-repository`, and `--branch-prefix`)
2. Jujutsu repository config ← where `jj spr init` writes
3. Jujutsu user config (`jj config path --user` prints where it is)
4. Git config (`.git/config`, then your global git config)
5. For the auth token only, the GitHub CLI (`gh auth token`)
6. Built-in defaults

## Configuration Values

jj-spr uses the following configuration values:

| config key           | CLI flag                          | description                                                                         | default[^default] | default in `jj spr init`[^initdefault]        |
| -------------------- | --------------------------------- | ----------------------------------------------------------------------------------- | ----------------- | --------------------------------------------- |
| `githubAuthToken`    | `--github-auth-token`[^cli-token] | The GitHub PAT (personal authentication token) to use for accessing the GitHub API. | the GitHub CLI's token, if `gh` is logged in | not written if you use the GitHub CLI's token |
| `githubRemoteName`   |                                   | Name of the git remote in this local repository that corresponds to GitHub          | `origin`          | `origin`                                      |
| `githubRepository`   | `--github-repository`             | Name of repository on github.com in `owner/repo` format                             | extracted from the URL of the GitHub remote | extracted from the URL of the GitHub remote   |
| `githubMasterBranch` |                                   | The name of the centrally shared branch into which the pull requests are merged     | `main`            | taken from repository configuration on GitHub |
| `branchPrefix`       | `--branch-prefix`                 | String used to prefix autogenerated names of pull request branches (required)       |                   | `spr/<GitHub username>/`                      |
| `requireApproval`    |                                   | If true, `jj spr land` will refuse to land a pull request that is not approved      | false             |                                               |
| `githubApiUrl`       |                                   | Base URL of the GitHub REST API; GraphQL requests go to `<githubApiUrl>/graphql`    | `https://api.github.com` | |

Notes:
- All config keys are in the `spr` section; for example, `spr.githubAuthToken`.
- Values passed on the command line take precedence over values set in configuration.

## Setting Configuration

### Option 1: Using jj spr init (Recommended)

The easiest way to configure jj-spr:

```shell
jj spr init
```

This writes settings to the repository's Jujutsu config (`jj config set --repo`).

### Option 2: Using jj config set

To change a single setting without rerunning `jj spr init`:

```shell
# Set repository-specific config (where jj spr init writes)
jj config set --repo spr.githubAuthToken "your-token"

# Set user-specific config (applies to all repos)
jj config set --user spr.branchPrefix "my-prefix/"
```

### Option 3: Editing config files directly

`jj config edit --repo` opens the file that `jj spr init` writes:
```toml
[spr]
githubAuthToken = "ghp_..."
githubRepository = "owner/repo"
githubRemoteName = "origin"
githubMasterBranch = "main"
branchPrefix = "spr/username/"
requireApproval = true
```

## Jujutsu-Specific Configuration

In addition to jj-spr settings, you may want to configure Jujutsu itself for optimal workflow:

```toml
# Recommended Jujutsu settings for jj-spr workflow
[ui]
default-command = "log"
pager = "less -FRX"

[revset-aliases]
# Useful revsets for jj-spr workflow
'mine' = 'author(exact:"your.email@example.com")'
'ready' = 'mine & ~description(regex:"^wip:")'
'has-pr' = 'mine & description(regex:"Pull Request:")'

[templates]
# Custom log format showing PR numbers
'log' = '''
label(if(current_working_copy, "bold"),
  concat(
    separate(" ",
      label("change_id", change_id.shortest(8)),
      label("description", if(description, description.first_line(), "(no description)")),
      if(!immutable,
         description.lines()
           .filter(|d| d.match(regex:'^Pull Request: https://.+/pull/(\d+)$'))
           .map(|d| hyperlink(
             d.remove_prefix("Pull Request: "),
             label("bookmark",
               d.replace(regex:'.*/pull/(\d+)$', '#$1')
             ))))
    )
  )
)
'''
```

[^default]: Value used by `jj spr` if not set in configuration.
[^initdefault]: Value suggested by `jj spr init` if not previously configured.
[^cli-token]: Be careful using this: your auth token will be in your shell history.
